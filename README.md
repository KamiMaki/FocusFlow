# FocusFlow

**把要記住的事交給系統，把注意力留給眼前的一件事。**

FocusFlow 是單人使用的專注與時間管理工具。完全在本機運作，不需要帳號、雲端服務或資料庫；資料保存在 `data/focusflow.json`。

## 日常流程

1. **安排今天**：新增任務、預估所需時間，看看是否超過今天可用的時間。
2. **專注一件事**：選一個任務，使用番茄鐘或碼表；需要安靜時開啟「專注模式」。
3. **隨手記下分心**：按「快速記下」或 `Ctrl / ⌘ + Shift + K`，留下念頭與提醒時間。計時不會因此中斷。
4. **休息時再處理**：查看提醒、延後 10 分鐘、轉成任務，或標記已處理。
5. **回顧今天**：查看工時與完成紀錄，匯出文字或 AI 整理 prompt。

## 功能

| 區域 | 能做什麼 |
|---|---|
| 今日安排 | 任務新增與編輯、時間預估、順序調整、專案篩選與管理、完成與恢復 |
| 時間預算 | 可用專注時間、待辦剩餘預估、超出預算的溫和提示 |
| 專注 | 番茄鐘／碼表、暫停原因、休息計時、下一步、任務筆記 |
| 稍後再想 | 快速記錄、下次休息／指定時間提醒、延後、完成、轉任務、AI 整理 |
| 提醒 | 頁面內提醒、專注時延後顯示、可選的無聲桌面通知 |
| 筆記與回顧 | 隨手筆記、待回覆清單、每日歷史、專案工時與中斷分析、日報匯出 |
| 外觀 | 夜色／日光、響應式配置、鍵盤操作、減少動態效果支援 |

## 開始使用

```bash
npm install
npm run dev
```

開啟終端機顯示的本機網址，預設為 `http://localhost:5173`。首次啟動是空白工作空間，不會加入範例任務。

也可以使用正式前端建置搭配本機預覽服務：

```bash
npm run build
npm run preview
```

`dev` 與 `preview` 都提供本機資料 API。單獨把 `dist/` 丟到靜態網站主機，無法讀寫本機 JSON。

## 計時與提醒

- 新使用者預設為 25 分鐘番茄鐘、5 分鐘休息；可以在設定中調整。既有檔案保留原本的計時模式。
- 切換任務、模式或完成任務前，會先保留已投入的工時。
- 番茄鐘到時自動停止並結算；休息不列入工時，不會自動開始下一段。
- 重新整理會依已儲存的開始時間恢復計時。**碼表會把離開頁面或休眠的時間也算進去，離開工作前請先暫停。** 番茄鐘最多只計到該段結束。
- 提醒需要保持頁面與本機服務開啟。關閉頁面或電腦休眠時，不保證能即時通知；重開後會列出已到期的提醒。
- 桌面通知預設關閉，只有按下「開啟桌面通知」才會請求瀏覽器權限。頁面內提醒不需要通知權限。
- 快捷鍵只在 FocusFlow 頁面內有效，並非作業系統全域快捷鍵。

## 資料與備份

- 任何變更通常在 0.5 秒後存檔，持續輸入時也會定期寫入。
- 儲存失敗會顯示提示，保留尚未儲存的內容，可手動重試或在連線恢復後重試。
- 寫入先存暫存檔再替換正式檔，降低部分寫入造成資料損壞的機會。
- 舊資料自動補齊新欄位；既有任務、筆記、靈感與歷史紀錄保留。
- 建議只使用一個分頁；尚未提供多分頁合併或多人協作。
- 備份時複製 `data/focusflow.json` 即可。請先暫停計時，並確認顯示「已儲存」。
