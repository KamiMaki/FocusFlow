# FocusFlow

**解放大腦記憶空間的個人工作任務管理器。**
把「記住事情」交給系統，把注意力留給眼前的那一件事。

單人使用、完全本機運作——無雲端、無帳號、無資料庫，所有資料就是一份好讀的 JSON 檔。

## 特色

- 🎯 **一次只專注一件事**——選定當前任務進入專注區，其他事務暫時退到視線之外
- ⏱️ **番茄鐘與碼表雙模式**——25 分鐘節奏或自由計時，工時自動累積到任務上
- 📝 **中斷有記錄、分心有數據**——每次暫停可記下原因（會議、訊息、分心…），日後統計成圖表
- 💡 **靈感收集箱**——想法閃過先丟進來，不打斷手上工作；之後可一鍵升級成任務，或產生 AI 整理 prompt
- 📊 **歷史與分析**——每日專注紀錄、趨勢圖、各專案工時、中斷原因分析與自動洞察
- 📤 **一鍵匯出日報**——把今天的任務、工時、想法整理成可直接貼給 AI 或主管的文字
- 🪶 **極簡技術棧**——Vite + React，依賴僅 5 個套件；`npm run dev` 一個指令就能開始用
- 💾 **資料完全屬於你**——單一 `data/focusflow.json`，純文字、可備份、可版本控制、可手動編輯

## 主要功能

### 今天視圖

| 區塊 | 功能 |
|---|---|
| 任務清單 | 新增任務、專案分類與篩選、專案管理（新增／改名／移除）、完成勾選、累積工時顯示 |
| 專注區 | 番茄鐘（25 分）／碼表、開始／暫停／完成流程、暫停原因記錄、「下一步」快速筆記、休息與閒置提醒 |
| 靈感與筆記 | 快速捕捉靈感、靈感升級為任務、產生 AI 整理 prompt、任務筆記與全域筆記、待回覆清單 |
| 匯出 | 產生今日工作摘要文字，一鍵複製 |

### 歷史與分析視圖

- 每日紀錄卡片（總專注時間、完成數、中斷次數），點選查看當日任務與暫停明細
- 7 日專注趨勢圖
- 各專案累積工時統計
- 中斷原因排行——看見自己最常被什麼打斷
- 依數據自動產生的洞察句

## 快速開始

```bash
npm install
npm run dev
```

打開終端機顯示的網址（預設 http://localhost:5173）即可使用。

## 資料與備份

- 全部資料存在 `data/focusflow.json`（純文字 JSON，直接複製即可備份）。
- 第一次啟動自動建立空白資料檔。
- 任何變更約 0.5 秒後自動存檔；關閉／切換分頁時也會即時寫入。
- 資料檔帶有世代標記（rev）：重置資料後，殘留的舊分頁無法把舊資料寫回。
- **清空重來**：停掉 dev server → 刪除 `data/focusflow.json` → 重新啟動即可。

## 技術架構

- Vite + React（純 JSX），依賴僅 react / react-dom / vite / @vitejs/plugin-react / vitest。
- 持久化：`vite.config.js` 內建小型 plugin 掛載 `/api/data`（GET 讀、PUT/POST 寫），以 Node `fs` 讀寫本機 JSON——不需要獨立後端。
- 純邏輯（日期、時間格式、彙整統計、匯出、跨日歸檔）集中在 `src/logic.js`，附單元測試。
- 全程使用本地日期基準與 `Date.now()` 差值計時，跨日自動把前一天歸檔進歷史。

## 測試

```bash
npx vitest run
```
