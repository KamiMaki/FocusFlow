# FocusFlow 初版發布 (2026-07-18)

## 概述

FocusFlow v1.0.0 是一個針對 ADHD 使用者的個人任務專注管理系統。完全本機運作、無雲端、無登入，所有資料存成一份簡潔易讀的 JSON 檔。

## 主要功能

### 今天頁面

- **任務清單**：建立每日任務、標記完成、按專案分類、累積工時追蹤
- **專注區**：
  - 碼表計時模式（自由計時）
  - 番茄鐘模式（25 分鐘計時 + 50 分鐘休息提醒）
  - 暫停原因記錄（會議、訊息回覆、被打斷等預設選項）
  - 任務完成流程（紀錄總結與改進方向）
- **下一步捕捉**：邊工作邊記錄冒出的想法，按時間戳記載
- **中斷紀錄**：自動列出今日所有暫停事件、原因與任務名
- **Idea 收集箱**：快速記錄靈感、轉換成任務、或產生 AI 整理 prompt
- **筆記面板**：全域筆記 + 待回覆訊息清單 + 任務專屬筆記
- **日報匯出**：生成今日統計 prompt，貼給 AI 快速整理成日報

### 歷史與分析頁面

- **每日紀錄卡**：過去 7 日快照，點擊查看當日明細
- **當日詳情**：已完成任務清單、中斷原因、各專案工時
- **7 日專注趨勢**：柱狀圖視覺化每日累積時間（含日均）
- **中斷原因分析**：統計過去 7 日最常見的中斷原因
- **各專案工時**：過去 7 日各專案累積時間排名

## 技術交付物

- **開發環境**：Vite v5.4 + React 18.3
- **依賴**：react、react-dom、vite、@vitejs/plugin-react、vitest
- **持久化**：自訂 Vite plugin 提供 `/api/data` GET/PUT 端點，讀寫本機 `data/focusflow.json`
- **測試**：19 個單元測試，覆蓋核心邏輯（日期、時間格式、聚合、匯出）
- **構建**：`npm run build` 生成 191.84 KB bundle（gzip 58.29 KB）

## 已知限制

- 單一分頁寫入：同時在多個分頁編輯會有衝突（JS 原生限制）
- 計時器掛起：硬重載（F5）後計時會暫停，需手動重新開始
- 跨日歸檔：日期翻天時會在載入時自動歸檔前一天到歷史
- 本機限制：資料只存在此機器，無跨裝置同步
