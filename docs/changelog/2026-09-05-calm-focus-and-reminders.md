# 專注流程與柔和介面更新

## 新增與改善

- 重整「今日安排 → 專注 → 稍後再想」工作面，加入專注模式，將筆記、中斷和已完成任務收合。
- 延續深色介面，降低色彩刺激；提供日光主題、響應式布局、清楚的鍵盤焦點與 reduced-motion。
- 任務可編輯、預留分鐘、調整順序；顯示可用時間和待辦預估。
- 分心快速記錄支援 Ctrl／⌘ + Shift + K、下次休息提醒、10／30／60 分鐘或指定時間。
- 提醒可延後、取消、已處理或轉成任務；完成紀錄可以恢復或確認刪除。
- 專注期間收好桌面提醒，暫停或休息後再顯示；桌面通知預設關閉且無音效。
- 可設定專注與休息長度；休息獨立計時，不會自動開始工作。

## 修正

- 切換任務或模式不再丟失已投入工時。
- 番茄鐘到期自動停止、結算一次，不會繼續累計超時。
- 暫停按鈕立即停止，選擇原因的時間不計入工作。
- 不再允許沒有任務或已完成的任務開始計時。
- 重新整理恢復已儲存的計時狀態；本地午夜分割工時並保留完整任務筆記快照。
- 載入失敗顯示重試入口；存檔失敗明確提示並保留最新內容供重試。
- 儲存依序送出，持續輸入不會無限延後保存；寫入使用暫存檔替換。
- `npm run preview` 同樣支援本機資料 API。

## 相容性與限制

舊 JSON 會補齊新欄位，任務、想法、筆記、專案與歷史保留；沒有新增套件或雲端服務。舊版歷史未保存的完整筆記無法補回。

提醒仍需開著本機服務與頁面。沒有背景推播；休眠或節流可能延後通知。碼表在離開頁面期間仍計入牆鐘時間，離開工作前請暫停。單一分頁使用，多分頁尚無衝突合併。
