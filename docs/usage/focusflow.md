# FocusFlow 使用指南

## 1. 安排今天

在「今日安排」新增一件任務，填入標題、專案與預留分鐘數。預估不用精確，按任務旁的編輯按鈕就能調整。

- 點任務選為當前專注；正在進行的任務會先結算工時，再切換並暫停。
- 按向上按鈕提前任務順序。
- 專案下拉選單可以篩選清單；「管理專案」提供新增、改名與移除。移除專案會保留其中的任務並歸到「未分類」。
- 上方顯示待辦還需多少時間，以及今天可用的專注時間。超出時可以減少安排、調整預估，或在設定修改可用時間。
- 已完成任務收在清單下方，可以恢復。

時間預算是「已投入工時＋未完成任務的剩餘預估」。它不是行事曆，也不會自動排定會議或確切開始時間。

## 2. 進入專注

在中間專注卡開始番茄鐘或碼表。按「專注模式」會收起兩侧的安排與收集箱，以及筆記、統計等次要內容；快速記錄與下一步仍保留。

- **番茄鐘**：預設 25 分鐘，到時自動停止並結算工時。可以選擇休息或繼續下一段。
- **碼表**：自由計時，約 50 分鐘會出現可略過的休息提示。
- **暫停一下**：按下立即停止計時；原因可選填，關閉視窗不會繼續計時。
- **休息**：預設 5 分鐘，獨立計時，不會算入任務工時。結束後由你決定何時繼續。
- **完成任務**：先暫停，成果與下次調整都是選填；確認後保留工時並選到下一件待辦。取消完成視窗時仍維持暫停。
- **下一小步**：記下與目前任務相關的小動作；不同的念頭則使用「快速記下」。

設定內可以調整每段專注、休息時間。進行中的段落保持原長度，新設定從下一段開始。

重新整理會恢復已儲存的計時狀態。碼表會計入關閉頁面、電腦休眠期間的時間；離開工作前請暫停。番茄鐘則以原定結束時間為上限。跨過本地午夜時，工時分入對應日期。

## 3. 把分心的念頭放下

按「快速記下」、專注卡下方的記錄入口，或 `Ctrl / ⌘ + Shift + K`。

1. 寫下想到的事。
2. 選擇提醒方式。
3. Enter 儲存並返回專注；Shift + Enter 換行，Esc 關閉。未送出的文字在本次頁面中保留，重新載入不保留草稿。

| 提醒方式 | 行為 |
|---|---|
| 下次暫停或休息時 | 在暫停、開始休息、番茄鐘結束、切換任務或模式、完成任務後出現；已在休息或未計時時記下會立即待提醒 |
| 10／30／60 分鐘後 | 按記錄時刻計算 |
| 指定時間 | 使用本地日期與時間，必須是未來時間 |
| 只記下 | 放在待整理清單，不發出提醒 |

預設開啟「專注時先收好提醒」。到期事項仍會保留，桌面通知留到暫停或休息時送出；專注畫面只顯示簡短的待提醒數量，也可自行選擇查看。

收集箱提供「待整理」「待提醒」「已處理」：

- **已處理**：保留紀錄，停止提醒；可以恢復。
- **轉為任務**：加入今日安排的「來自 Idea」專案，原紀錄移到已處理。
- **10 分後**：延後提醒，可以再次延後。
- **點提醒時間**：重新設定提醒。
- **更多 → 取消提醒**：保留文字，不再提醒。
- **更多 → AI 整理**：產生分階段任務 prompt，複製後貼給 AI。
- **已處理 → 刪除**：確認後永久刪除；不需要刪除時可以留在已處理。

## 4. 通知的使用條件

頁面內提醒不需權限。桌面通知在偏好設定中手動開啟，預設關閉，且不播放音效。

請保持 FocusFlow 頁面與 `npm run dev` 或 `npm run preview` 本機服務開啟。頁面關閉、電腦休眠或瀏覽器節流時無法保證即時提醒；重新開啟後會顯示已到期的紀錄。此版本不提供背景推播、寄信或手機同步通知。

如果瀏覽器封鎖通知，可在網站權限中調整；頁面內提醒仍可使用。快捷鍵只作用於 FocusFlow 網頁，不是系統全域快捷鍵。

## 5. 筆記、回顧與匯出

展開「筆記與待回覆」，使用目前任務的筆記、全域隨手筆記或待回覆清單。筆記改動會自動儲存。

「回顧」保留每日任務、專注時間與中斷紀錄，並顯示最近 7 日的專注趨勢、各專案工時與常見中斷原因。歷史最多保留 90 日；舊版歷史若未記下完整筆記，不能事後還原。

今天頁面底部可以匯出今日紀錄文字，含任務成果、工時、中斷、待整理想法與隨手筆記。複製失敗時可以在文字框中手動全選複製。

## 6. 外觀與儲存

「夜色」延續低亮度介面；「日光」適合明亮環境。頁面不使用閃爍或循環動畫；若系統要求減少動態效果，互動過渡也會停用。

資料仍在 `data/focusflow.json`。首次啟動是空白資料，舊檔案會補齊新欄位。只建議單一分頁編輯，尚無多分頁合併機制。

- **讀取失敗**：顯示重試頁面，編輯與自動寫入不會啟動。
- **儲存失敗**：畫面顯示「尚未存檔」，資料保留在頁面中，按「重試儲存」。離開有未確認寫入的頁面時，瀏覽器可能會詢問是否離開。
- **資料已重置**：舊分頁不會再寫入，先複製未儲存文字後再重新載入。

備份前先暫停計時，等待「已儲存」，再複製 JSON 檔。請勿在服務運行且頁面仍編輯時手動覆寫該檔案。
