# FocusFlow 使用指南

FocusFlow 是為 ADHD 使用者設計的個人任務專注管理系統。幫你專注當下、記錄想法、分析規律，解放大腦的記憶空間。

## 安裝與啟動

### 首次安裝

1. 打開終端機，進入專案目錄：
   ```bash
   cd FocusFlow
   ```

2. 安裝依賴：
   ```bash
   npm install
   ```

3. 啟動開發伺服器：
   ```bash
   npm run dev
   ```

4. 打開顯示的網址（預設 http://localhost:5173）
5. 首次啟動時會自動建立 `data/focusflow.json`，載入預設範例資料

### 日常啟動

直接執行 `npm run dev`，打開 http://localhost:5173。

## 資料存哪裡

- **檔案位置**：`data/focusflow.json`（專案根目錄）
- **備份方式**：
  - 手動複製 `data/focusflow.json` 到安全位置
  - 或納入版本控制（git）並忽略 `data/` 目錄（已在 `.gitignore` 中）
  - 或定期用雲端同步工具（OneDrive、iCloud Drive 等）

## 功能介紹

### 💡 今天頁面（主工作面）

#### 左欄 — 今日任務清單

- **新增任務**：在「新增任務」欄位輸入，按 Enter 送出
- **選擇專案**：新增前點選下方的專案晶片，或後來在任務卡上點擊專案晶片切換
- **完成任務**：點擊任務卡左邊的勾選框標記完成
- **切換當前任務**：點擊任務卡切換焦點
- **管理專案**：點擊「✎ 管理」開啟專案管理面板
  - 重新命名專案
  - 新增專案
  - 移除專案（任務會自動歸到「未分類」）
- **今日統計**：顯示完成數、中斷次數、Idea 數量，以及各專案的累積工時

#### 中欄 — 專注區

**計時模式**
- 點擊「碼表」：自由計時（不限時間）
- 點擊「番茄鐘」：25 分鐘計時 + 自動提醒

**計時控制**
- **▶ 開始專注**：開始計時
- **⏸ 暫停**：暫停計時，選擇中斷原因（會議、訊息回覆、被打斷、分心了、休息、換任務）
- **✓ 完成任務**：開啟完成流程，紀錄做了什麼與改進方向

**下一步捕捉**
- 工作途中想到什麼先寫下來，不打斷當前計時
- 按 Enter 存入清單
- 每條記錄都帶時間戳（HH:MM）

**中斷紀錄**
- 自動列出今日所有暫停的原因與任務名
- 幫你了解最常見的專注破壞因素

#### 右欄 — 想法與筆記

**Idea 收集箱**
- 用右下角的 ＋ 按鈕快速記錄靈感
- 每條 idea 可以：
  - **AI 整理**：複製一份 prompt，貼給 AI（ChatGPT 等），讓它幫你分解成可執行的子任務
  - **開成任務**：直接轉換成一個新任務（自動歸到「來自 Idea」專案）
  - **刪除**：移除不需要的想法

**筆記面板**（兩個分頁）
- **筆記**：全域自由筆記區，記會議重點、暫存文字、任何不想佔用腦容量的東西
- **待回覆訊息**：記錄要回覆誰、什麼事，可勾選標記已回

**任務筆記**
- 當前任務的專屬筆記空間
- 記錄進度、相關連結、參考資料

### 📊 歷史與分析頁面

點擊右上角「歷史與分析」進入。

#### 左欄 — 每日紀錄

- 列出過去 7 日的快照卡片（最上面是今天）
- 每張卡片顯示該日的累積時間和完成任務數
- 點擊卡片查看當日詳情

#### 中欄 — 當日明細

- **任務清單**：該日完成的任務、所屬專案、累積時間
- **中斷紀錄**：該日所有暫停事件（時間、原因、任務名）

#### 右欄 — 分析統計

- **7 日專注趨勢**：柱狀圖顯示每日累積時間，日均統計
- **中斷原因分析**：過去 7 日最常見的中斷原因排名（含次數）
- **各專案工時**：過去 7 日各專案的累積時間排名

### 📋 日報匯出

在「今日統計」卡片點擊「📋 匯出日報 Prompt」，會生成一份結構化的統計文本。複製這份文本貼給 AI，它會幫你整理成日報。

## 進階用法

### 快速記錄 Idea（不中斷工作）

1. 工作途中想到事情，不要停止計時
2. 按右下角的 ＋ 按鈕（或按 Escape 關閉後再按）
3. 快速輸入想法，按 Enter 或點「存入收集箱」
4. 回到專注工作
5. 稍後空閒時在 Idea 收集箱檢視、整理、或開成任務

### 使用番茄鐘建立節奏

1. 點「番茄鐘」切換模式
2. 按「開始專注」
3. 25 分鐘後會出現「建議休息」提醒
4. 休息 5–10 分鐘，按「繼續任務」回到下一個番茄鐘
5. 番茄鐘完成後會自動停止，按「知道了」確認

### 分析工作規律

1. 連續用 FocusFlow 7 天以上
2. 進入「歷史與分析」頁面
3. 查看「中斷原因分析」——最常見的干擾是什麼？
4. 根據數據調整工作環境或流程（例如開會前集中回訊息）

## 常見問題

### 資料會不會丟？

- FocusFlow 在每次變更後約 500ms 自動存檔
- 切換分頁或關閉頁面時會立即存檔（用 sendBeacon 技術）
- 資料存在本機 `data/focusflow.json`，只要檔案不被刪除就安全

### 要清空重來怎麼辦？

1. 關閉瀏覽器標籤
2. 刪除 `data/focusflow.json`
3. 重新整理頁面，會自動建立預設資料

### 為什麼硬重載（F5）後計時停了？

計時器是基於瀏覽器的 `Date.now()` 計算，F5 會重新載入頁面造成計時中斷。目前的設計讓計時暫停，之後手動「開始專注」即可恢復。

### 能不能在多個分頁同時編輯？

不建議。FocusFlow 使用本機單一檔案存儲，多分頁併發會有衝突。建議只在一個分頁使用。

### 資料可以同步到手機嗎？

目前沒有內建雲同步。可以手動備份 `data/focusflow.json` 到雲端（OneDrive、Google Drive 等），或使用 Syncthing 等工具同步。

## 故障排查

### 「載入中…」沒有完成

- 檢查瀏覽器控制台（F12）有沒有紅色錯誤
- 確認 `npm run dev` 的伺服器還在執行
- 重新整理頁面（Ctrl+Shift+R 清除快取）

### 資料保存失敗

- 檢查 `data/` 目錄是否存在且有寫入權限
- 檢查瀏覽器控制台的錯誤訊息
- 重啟開發伺服器：Ctrl+C 停止，重新執行 `npm run dev`

### 計時器顯示錯誤

- 重新整理頁面
- 檢查電腦系統時間是否正確

## 鍵盤快捷鍵

- **Escape**：關閉 Idea 快速記錄面板或暫停原因面板
- **Enter**：在各輸入框送出（新任務、下一步、Idea 等）

## 建議工作流

1. 早上打開 FocusFlow，新增今日任務清單
2. 每個任務開始前點「開始專注」
3. 中斷時按「暫停」並選原因
4. 工作途中想法用右下 ＋ 快速記錄
5. 任務完成按「完成任務」紀錄成果
6. 晚上進入「歷史與分析」查看統計
7. 週末檢視「中斷原因分析」調整下週計畫
